# كبابجي البرنس | Kababgy Al Prince — Restaurant Ordering Platform

تطبيق متكامل واحترافي لطلبات المطعم وإدارتها، مبني بأحدث التقنيات لنظام **كبابجي البرنس (Kababgy Al Prince)**.

---

## 🌟 الميزات الرئيسية (Key Features)

### 🛒 للعميل (Customer Facing Platform):
- **تحديد الفرع المفضل:** إمكانية اختيار الفرع (المقطم، فيصل، إمبابة) واستمرار حفظ الفرع في المتصفح مع تكييف المنيو ورسوم التوصيل.
- **منيو تفاعلي وأصناف متغيرة:** تصفح المشويات على الفحم، صواني البرنس، المندي، الطواجن بالسمن البلدي، والحمام المحشي بأوزان وأحجام مختلفة (كيلو، نص، ثلت، ربع).
- **تخصيص الوجبات:** نافذة تفاعلية لتحديد الأوزان والإضافات (طحينة، مخلل، عيش بلدي) والملاحظات الخاصة.
- **حساب التوصيل والحد الأدنى التلقائي:** حساب رسوم التوصيل ديناميكياً حسب المنطقة والفرع المختار، وشريط ينبه العميل بالمبلغ المتبقي للحد الأدنى.
- **تذكر بيانات العميل:** حفظ أحدث عنوان واسم ورقم هاتف لاستخدامه مباشرة عند العودة ("أهلاً بيك 👋 نستخدم آخر عنوان؟").
- **رسالة WhatsApp منسقة وتلقائية:** إنشاء كود طلب فريد فريد وحسابه على السيرفر لتوليد رابط `wa.me` منسق بكافة الأصناف والعنوان المباشر للمطعم.
- **تتبع الطلبات وحساب العميل:** متابعة مرحلة سير الطلب من خلال التايم لاين، وإمكانية إعادة الطلب بضغطة زر واحدة (Reorder).

### 🔐 لوحة تحكم الإدارة (Admin Dashboard):
- **حماية آمنة وإدارة الجلسة:** تسجيل دخول منفصل للمديرين عبر `/admin/login`.
- **نظرة عامة وإحصائيات:** عدد طلبات اليوم، إيرادات اليوم، الطلبات المعلقة، والصنف الأكثر مبيعاً.
- **جدول الطلبات وتحديث الحالات:** إمكانية تغيير حالة الطلب (جديد 🟡، تم التأكيد 🔵، جاري التحضير 🔥، جاهز 📦، تم التسليم 🟢، ملغي 🔴).
- **إدارة أصناف المنيو والأقسام (CRUD):** إضافة، تعديل الأسعار، تفعيل/إيقاف صنف، وتعليم الأصناف الأكثر طلباً أو المميزة.
- **إدارة مناطق ورسوم التوصيل:** تعديل رسوم التوصيل والحد الأدنى لكل منطقة سكنية.
- **إعدادات المطعم العامة:** تعديل رقم الواتساب المباشر (`01288883934`)، الخط الساخن، شريط الإعلانات، وتفعيل وضع الصيانة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Framer Motion, Lucide React, Canvas Confetti.
- **Backend & Database:** Supabase (PostgreSQL, Row Level Security, Supabase Auth).
- **State & Local Storage:** React Context API + LocalStorage / SessionStorage persistence.

## 🚀 كيفية التشغيل والمشروع (Local Setup)

1. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   ```

2. **ضبط متغيرات البيئة (Environment Variables):**
   قم بإنشاء ملف `.env.local` مستنداً إلى `.env.example`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-supabase-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key
   ```

3. **إعداد قاعدة البيانات (Database Setup):**
   - نفذ ملف `supabase/schema.sql` في Supabase SQL Editor لإنشاء الجداول وسياسات الأمن RLS.
   - نفذ ملف `supabase/seed.sql` لإدراج الأصناف والأسعار الحقيقية والفروع.

4. **تشغيل السيرفر المحلي (Run Development Server):**
   ```bash
   npm run dev
   ```
   افتح [http://localhost:3000](http://localhost:3000) في المتصفح.
